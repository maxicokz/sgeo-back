## Детали интеграций

### OpenRouter API

- **Base URL:** `https://openrouter.ai/api/v1`
- **Метод аутентификации:** Bearer Token в заголовке `Authorization`
- **Используется в:** `OpenRouterService.php`
- **Данные в запросе:** текстовые промпты, параметры моделей. **Персональные данные пользователей НЕ передаются.**
- **Резервный план:** при недоступности сервиса — вернуть ошибку, логировать.

### PostgreSQL / Supabase

- **Драйвер:** PDO (`pdo_pgsql`)
- **SSL:** обязателен на продакшне (`sslmode=require`)
- **Конфигурация:** `config/database.php`, переменные `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`
- **Бэкапы:** ежедневно (ответственность DevOps / Supabase автоматика)

### DomPDF

- **Версия:** `^2.0`
- **Назначение:** генерация PDF-отчётов (`ReportService.php`)
- **Сеть:** не обращается к внешним ресурсам
- **Безопасность:** отключить `DOMPDF_ENABLE_PHP` (по умолчанию выключено в v2)

## Правила добавления новых интеграций

1. Добавить строку в эту таблицу.
2. Зарегистрировать ключ в `SecretsManager::REQUIRED`, если ключ обязателен при запуске.
3. Оформить через `SecretsManager::get()` — не читать `$_ENV` напрямую.
4. Указать срок ротации и ответственного.
5. Убедиться, что ключ добавлен в `.env.example` (без реального значения).
