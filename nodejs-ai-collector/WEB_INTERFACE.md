# Веб-интерфейс AI Responses Collector

Руководство по использованию веб-интерфейса для сбора AI ответов.

## 🚀 Запуск

### Быстрый старт

1. **Убедитесь, что зависимости установлены:**
```bash
cd nodejs-ai-collector
npm install
```

2. **Настройте .env файл** (см. INSTALLATION.md)

3. **Запустите веб-сервер:**
```bash
npm run web
```

4. **Откройте браузер:**
```
http://localhost:3000
```

### Режим разработки с автоперезагрузкой:
```bash
npm run web:dev
```

### Изменение порта:
```bash
PORT=8080 npm run web
```

## 📊 Интерфейс

### 1. Панель статистики

В верхней части страницы отображается:
- **Всего ответов** - общее количество собранных ответов
- **Моделей** - количество использованных моделей
- **Языков** - количество определенных языков

Статистика автоматически обновляется после каждого запроса.

### 2. Панель создания запроса (слева)

#### Ввод промпта
- Текстовое поле для ввода вашего вопроса или промпта
- Поддерживает многострочный текст
- Можно использовать любой язык

#### Примеры промптов
Готовые кнопки с популярными запросами:
- Клик по кнопке автоматически заполняет поле промпта
- Можно редактировать вставленный текст

#### Выбор моделей
- Чекбоксы для выбора AI моделей
- Можно выбрать одну или несколько моделей одновременно
- Доступные модели:
  - **ChatGPT** - GPT-5.1 Chat (новейшая версия)
  - **DeepSeek** - DeepSeek V3 (эффективная и доступная)
  - **Copilot** - Microsoft Copilot (GPT-4)
  - **Perplexity** - Perplexity Sonar Pro
  - **Gemini** - Google Gemini 2.5 Flash

#### Кнопки действий
- **🚀 Собрать ответы** - запускает сбор ответов от выбранных моделей
- **🗑️ Очистить** - очищает форму

#### Прогресс выполнения
Показывается во время обработки запроса:
- Индикатор прогресса
- Текстовое описание статуса

### 3. Панель результатов (справа)

#### Фильтры
- **Модель** - фильтр по конкретной модели
- **Лимит** - количество записей для отображения (по умолчанию 20)
- **🔄 Обновить** - обновить таблицу результатов

#### Таблица результатов
Столбцы:
- **Дата** - дата и время создания ответа
- **Модель** - название AI модели
- **Промпт** - исходный запрос (обрезан для компактности)
- **Ответ** - текст ответа (обрезан для компактности)
- **Язык** - определенный язык запроса
- **Действия** - кнопка "Просмотр" для детального просмотра

#### Детальный просмотр
При клике на "Просмотр" открывается модальное окно с полной информацией:
- Полный текст промпта
- Полный текст ответа
- Модель
- Язык
- Дата создания
- Метаданные (токены, время ответа, и т.д.)

## 🔧 API Endpoints

Веб-интерфейс использует следующие API endpoints:

### GET /api/models
Получить список доступных моделей

**Ответ:**
```json
{
  "success": true,
  "models": [
    {
      "id": "chatgpt",
      "name": "Chatgpt"
    }
  ]
}
```

### POST /api/collect
Собрать ответы от AI моделей

**Запрос:**
```json
{
  "prompt": "Что такое AI?",
  "models": ["chatgpt", "gemini"]
}
```

**Ответ:**
```json
{
  "success": true,
  "language": "ru",
  "results": {
    "successful": 2,
    "failed": 0,
    "total": 2
  },
  "responses": [...],
  "errors": []
}
```

### GET /api/responses
Получить список ответов

**Параметры:**
- `limit` - количество записей (default: 50)
- `modelName` - фильтр по модели (опционально)
- `language` - фильтр по языку (опционально)

**Ответ:**
```json
{
  "success": true,
  "count": 20,
  "responses": [...]
}
```

### GET /api/responses/:id
Получить конкретный ответ по ID

**Ответ:**
```json
{
  "success": true,
  "response": {
    "id": "uuid",
    "prompt": "...",
    "model": "chatgpt",
    "response": "...",
    "language": "ru",
    "metadata": {...},
    "createdAt": "2024-01-01T00:00:00Z"
  }
}
```

### GET /api/statistics
Получить статистику

**Ответ:**
```json
{
  "success": true,
  "statistics": {
    "total": 100,
    "byModel": {
      "chatgpt": 50,
      "gemini": 50
    },
    "byLanguage": {
      "ru": 60,
      "en": 40
    }
  }
}
```

### GET /api/sample-prompts
Получить примеры промптов

**Ответ:**
```json
{
  "success": true,
  "prompts": {
    "general": [...],
    "russian": [...],
    "kazakhstan": [...]
  }
}
```

## 💡 Примеры использования

### Пример 1: Простой запрос
1. Введите в поле промпта: "Что такое искусственный интеллект?"
2. Выберите модель "ChatGPT"
3. Нажмите "Собрать ответы"
4. Дождитесь результата
5. Просмотрите ответ в таблице

### Пример 2: Сравнение моделей
1. Введите: "Объясни квантовые вычисления"
2. Выберите все доступные модели
3. Нажмите "Собрать ответы"
4. Сравните ответы разных моделей в таблице

### Пример 3: Работа с историей
1. Используйте фильтр по модели для просмотра ответов конкретной модели
2. Измените лимит для отображения большего количества записей
3. Нажмите "Просмотр" для детального изучения ответа

## 🎨 Кастомизация

### Изменение стилей
Отредактируйте файл `/public/css/styles.css`:
```css
:root {
    --primary-color: #4f46e5;  /* Основной цвет */
    --primary-hover: #4338ca;  /* Цвет при наведении */
    /* ... другие переменные */
}
```

### Добавление новых промптов
Отредактируйте файл `/public/index.html`, секцию с примерами промптов:
```html
<button class="sample-btn" data-prompt="Ваш промпт">
    Название кнопки
</button>
```

### Изменение порта по умолчанию
В файле `/src/server.js`:
```javascript
const PORT = process.env.PORT || 3000; // Измените 3000 на нужный порт
```

Или через переменную окружения в `.env`:
```env
PORT=8080
```

## 🔒 Безопасность

### Рекомендации:
1. **Используйте HTTPS** в production
2. **Настройте CORS** в `src/server.js` для ограничения доступа
3. **Добавьте аутентификацию** если требуется ограничить доступ
4. **Валидируйте входные данные** на сервере
5. **Ограничьте rate limiting** для защиты от злоупотреблений

### Пример добавления аутентификации:
```javascript
// В src/server.js
app.use((req, res, next) => {
  const apiKey = req.headers['x-api-key'];
  if (apiKey !== process.env.API_KEY) {
    return res.status(401).json({ error: 'Unauthorized' });
  }
  next();
});
```

## 🚀 Production Deployment

### Для деплоя на production:

1. **Установите переменные окружения:**
```bash
export NODE_ENV=production
export PORT=80
```

2. **Используйте process manager (PM2):**
```bash
npm install -g pm2
pm2 start src/server.js --name ai-collector
pm2 save
pm2 startup
```

3. **Настройте reverse proxy (Nginx):**
```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

4. **Настройте SSL с Let's Encrypt:**
```bash
sudo certbot --nginx -d your-domain.com
```
