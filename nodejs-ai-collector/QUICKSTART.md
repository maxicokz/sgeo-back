# Быстрый старт - AI Responses Collector

Руководство для быстрого начала работы с веб-интерфейсом.

## ⚡ Запуск за 5 минут

### 1. Установка

```bash
cd nodejs-ai-collector
npm install
```

### 2. Настройка

Скопируйте пример конфигурации:
```bash
cp .env.example .env
```

Откройте `.env` и заполните минимум:
```env
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ
SUPABASE_URL=https://ваш-проект.supabase.co
SUPABASE_ANON_KEY=ваш-анонимный-ключ
```

### 3. База данных

1. Откройте [Supabase](https://supabase.com/)
2. Создайте новый проект (если ещё нет)
3. Перейдите в SQL Editor
4. Скопируйте содержимое файла `database/schema.sql`
5. Выполните запрос

### 4. Запуск

```bash
npm run web
```

Откройте: **http://localhost:3000**

## 🎯 Первый запрос

1. **Введите промпт** в текстовое поле, например:
   ```
   Что такое искусственный интеллект?
   ```

2. **Выберите модель** (например, ChatGPT)

3. **Нажмите "Собрать ответы"**

4. **Дождитесь результата** - он появится в таблице справа

5. **Нажмите "Просмотр"** для детальной информации

## 🚀 Сравнение моделей

1. Введите промпт:
   ```
   Объясни квантовые вычисления простыми словами
   ```

2. **Выберите несколько моделей** (ChatGPT, Gemini, Perplexity)

3. Нажмите "Собрать ответы"

4. **Сравните ответы** в таблице результатов

## 📊 Просмотр истории

- Используйте **фильтр по модели** в правой панели
- Измените **лимит записей** (по умолчанию 20)
- Нажмите **🔄 Обновить** для обновления таблицы

## 🔑 Где взять ключи?

### OpenRouter API Key

1. Регистрация: [openrouter.ai](https://openrouter.ai/)
2. Пополнить баланс: минимум $5
3. Создать ключ: раздел **Keys**
4. Скопировать и вставить в `.env`

### Supabase

1. Создать проект: [supabase.com](https://supabase.com/)
2. Settings → API
3. Скопировать:
   - Project URL
   - anon public key
4. Вставить в `.env`

## ❓ Частые проблемы

### "Configuration error"
- Проверьте, что `.env` файл создан
- Убедитесь, что все 3 ключа заполнены
- Перезапустите сервер

### "relation ai_responses does not exist"
- Выполните SQL из `database/schema.sql` в Supabase
- Проверьте, что запрос выполнился без ошибок

### "Insufficient funds" или ошибки API
- Проверьте баланс OpenRouter
- Убедитесь, что API ключ правильный

### Страница не открывается
- Проверьте, что сервер запущен (`npm run web`)
- Попробуйте другой порт: `PORT=8080 npm run web`
- Проверьте, что порт не занят другим приложением
